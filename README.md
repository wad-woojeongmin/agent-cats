# 고양이 팀

Claude Code 세션 하나를 고양이 한 마리로 보여주는 로컬 화면입니다. 일하는 중이면 타닥타닥 치고, 쉬는 중이면 몸을 말고 잡니다.
말풍선은 그 세션이 지금 무슨 일을 하는지 알려줍니다. 서버도 계정도 필요 없고, 밖으로 나가는 데이터가 없습니다.

## 쓰는 법

1. `팀.json` 을 열어 고양이를 고칩니다 (아래 "고양이 추가"). `팀.json` 은 내 컴퓨터에만 두는 설정이라 git 에 올라가지 않습니다. 없으면 `수집.py` 나 앱을 처음 켤 때 `팀.example.json` 을 복사해 만들어 주고, 직접 복사해도 됩니다.
2. 터미널에서 수집기를 켭니다. 화면을 열어 두는 동안 켜 둡니다.

```bash
python3 수집.py --loop
```

3. `index.html` 을 더블클릭해서 엽니다. 15초마다 저절로 갱신됩니다.

수집기가 꺼져 있으면 화면 위에 "수집기가 꺼져 있어요"가 뜨고, 오른쪽 위에 마지막 갱신 시각이 항상 보입니다.

## 고양이 추가 (`팀.json` 한 줄)

`팀.json` 이 없으면 `cp 팀.example.json 팀.json` 으로 만들거나, 수집기나 앱을 한 번 켜면 저절로 생깁니다.

| 항목 | 뜻 |
| --- | --- |
| `key` | 겹치지 않는 영문 이름 |
| `hidden` | (선택) true 면 두 화면 모두에서 숨깁니다 (데스크톱 앱의 표시 토글이 씁니다) |
| `name`, `role` | 고양이 아래 이름표는 "이름 직군"으로 나옵니다. 이름이 없으면 직군만 나옵니다 |
| `variant` | 품종: `white`, `tabby`(줄무늬), `gray`, `tux`(턱시도), `siamese`(샴) |
| `prop` | 소품: `headphones`, `glasses`, `postit`, `chart`, `paper`, 비우면 컵만 |
| `match` | 찾을 말 목록. 세션 제목이나 작업 폴더 **경로 전체**에 하나라도 들어 있으면 이 고양이 담당입니다 (대소문자 무시, 유사어를 같이 적으세요) |
| `task` | (선택) 일하는 중에 말풍선 제목으로 쓸 말. 없으면 "폴더이름 작업중" |
| `fixed` | (선택) 세션과 무관하게 고정으로 띄울 상태. 모니터 없이 소품을 들고 앉아 기다립니다 |
| `private` | (선택) true 면 세션의 마지막 보고 문장을 읽어 오지 않습니다 (도구 이름과 시각만) |

여러 세션이 걸리면 가장 최근에 움직인 세션 하나가 그 고양이의 상태가 됩니다. 아무 세션도 안 걸리면 "아직 일을 시작 안 했어요"로 잡니다.
`팀.json` 은 수집기가 10초마다 다시 읽으니 고친 뒤 바로 반영됩니다.

## 말풍선 읽는 법

- 첫 줄: 일하는 중이면 "{업무명} 작업중..", 쉬는 중이면 "잠깐 쉬는 중"
- 둘째 줄: 지금 진행 중인 작업 (마지막 보고의 첫 문장, 없으면 쓴 도구와 대상)
- 셋째 줄: 마지막 움직임이 언제였는지

일하는 중 판정은 두 가지입니다. 기록이 5분 안에 움직였거나, 기록이 조용해도 응답이 아직 안 끝났으면(긴 도구나 에이전트를 기다리는 중) 45분까지는 일하는 중으로 봅니다.

## 데스크톱 앱 (macOS)

브라우저 대신 데스크톱 위에서 고양이가 돌아다니게 할 수 있습니다. 메뉴 막대에 🐱 아이콘만 뜨는 앱이고, 수집기도 앱이 직접 켜고 끕니다(터미널에서 따로 켤 필요 없음).

```bash
bash desktop/build.sh      # 이 폴더에 고양이팀.app 을 만든다
open 고양이팀.app
```

- 앱은 `desktop.html` 과 `팀.json` 이 있는 이 폴더 안에 그대로 두세요. 앱이 놓인 폴더를 프로젝트 폴더로 씁니다.
- 고양이를 **클릭**하면 자세한 말풍선이 뜨고, **끌어서** 옮길 수 있습니다. 창 윗변이나 메뉴 막대 근처에 놓으면 그 위에 앉습니다.
- **우클릭**: 여기에 고정 / 고정 풀기, 숨기기, 팀원 관리 열기.
- 고양이가 없는 곳의 클릭은 모두 아래 창으로 그대로 갑니다.
- 디스플레이가 여러 개면 디스플레이마다 고양이를 나눠 띄웁니다. 고양이는 자기 디스플레이 안에서만 돌아다닙니다.
  - 처음에는 고양이가 적은 디스플레이부터 차례로 나누고, 한 번 정해진 자리는 기억합니다. 다른 고양이를 옮겨도 나머지는 그대로 있습니다.
  - 우클릭 → "다른 디스플레이로 보내기"나 팀원 편집의 "디스플레이"로 옮깁니다. "고양이가 적은 화면으로"를 고르면 그 순간 가장 한가한 화면으로 갑니다.
  - 자리의 디스플레이를 빼면 그동안은 주 화면에 있다가, 다시 꽂으면 돌아갑니다. 새로 꽂은 디스플레이에는 직접 보낸 고양이만 갑니다.
- 메뉴 막대 🐱:
  - 펫 활성화
  - 팀원 관리: 순서, 이름, 품종, 소품, 찾을 말, 업무명, 표시 여부. 저장하면 `팀.json` 에 씁니다.
  - 행동 설정: 행동별 켜고 끄기, 활동량, 말풍선 주기
  - 기타 설정: 투명도, 크기, 로그인 시 실행, 수집기 상태, 모든 고정 풀기
- "파일/폴더와 놀기"는 Finder 에 아이콘 위치를 물어봅니다. 처음에 자동화 권한을 묻고, 거부하면 그 행동만 꺼집니다.
- 브라우저에서 `desktop.html?demo` 를 열면 가짜 창과 아이콘을 둔 시험 화면이 됩니다(우클릭이 곧 고정).
- 화면을 고쳤으면 메뉴 막대 → 기타 설정 → 화면 새로고침, Swift 코드를 고쳤으면 다시 빌드하세요.

## 새 품종이나 소품 만들기

- 품종: `palette.js` 의 `CAT_VARIANTS` 에 한 줄을 더합니다 (색 덮어쓰기와 무늬 방식 `patch`/`stripes`/`mask`).
- 소품: `props.js` 에 함수를 더합니다 (`head`, `monitor`, `screen` 중 필요한 것).
- 그림은 44x25칸의 도트이고 면만 채우면 테두리는 자동으로 둘러집니다 (`pose-sit.js`, `pose-sleep.js`, `pose-move.js`).
- 데스크톱의 움직이는 자세(`pose-move.js`)는 오른쪽을 보는 옆모습이고 발끝은 20번 줄입니다. 안경과 헤드폰은 `props.js` 의 `"side"` 로 얹습니다.

## 개인정보

- 수집기가 읽는 것은 세션 제목, 작업 폴더 경로, 마지막 활동 시각, 마지막 도구와 대상, 마지막 보고의 첫 문장입니다. 대화 전체를 저장하거나 보내지 않습니다.
- 민감한 내용이 오갈 수 있는 팀은 `private: true` 로 두세요.
- `status.js` 는 실행할 때마다 바뀌는 파일이라 `.gitignore` 에 들어 있습니다.
- `팀.json` 도 프로젝트나 폴더 이름이 들어갈 수 있어 `.gitignore` 에 들어 있습니다. 공유할 예시는 `팀.example.json` 에 둡니다.

## 자주 막히는 곳

- 모든 고양이가 "아직 일을 시작 안 했어요"로 잔다: `match` 에 적은 말이 폴더 경로나 세션 제목에 실제로 있는지 확인하세요.
- 옛 화면이 보인다: 주소 뒤에 `?v=2` 처럼 붙여 새로고침하세요.
- 수집기를 고쳤는데 그대로다: `--loop` 로 켜 둔 프로세스를 끄고 다시 켜세요.
- 세션이 목록에 안 잡힌다: 앱에서 연 세션은 앱의 세션 목록에서, 터미널에서 연 세션은 `~/.claude/projects` 의 기록 파일에서 찾습니다. 최근 이틀 안에 움직인 세션만 봅니다.

| `팀.json` | 고양이 설정 (여기만 고치면 됩니다). 내 컴퓨터에만 두는 파일이라 git 에 안 올라갑니다 |
| `팀.example.json` | `팀.json` 예시. `팀.json` 이 없으면 처음 실행할 때 이걸 복사합니다 |

| `lines.js` | 상태별 말풍선 문구 (두 화면이 함께 씀) |
| `desktop.html`, `desktop.css` | 데스크톱 앱 화면 |
| `desk-world.js`, `desk-brain.js`, `desk-view.js` | 데스크톱 세계(창·메뉴 막대·아이콘), 고양이 행동, 그리기와 조작 |

| `팀.테스트.json` | 이 폴더를 만들 때 쓴 실제 세션용 시험 설정 (지워도 됩니다) |
