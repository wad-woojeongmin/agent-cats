# 고양이 팀

Claude Code 세션 하나를 도트 고양이 한 마리로 보여주는 로컬 화면입니다. 일하는 중이면 타닥타닥 치고, 쉬는 중이면 몸을 말고 잡니다.
말풍선은 그 세션이 지금 무슨 일을 하는지 알려줍니다. 서버도 계정도 필요 없고, 밖으로 나가는 데이터가 없습니다.

![데스크톱에서 돌아다니는 고양이들](docs/screenshot.png)

시험용 데모 화면(`desktop.html?demo`)을 찍은 것입니다.

## 준비물

- macOS 14 이상 (데스크톱 앱)
- Command Line Tools: `python3` 와 `swiftc` 가 들어 있습니다. 없으면 `xcode-select --install` 로 설치하세요. 앱은 `/usr/bin/python3` 으로 수집기를 돌립니다.
- Node 는 테스트를 돌릴 때만 필요합니다.

이 Mac 에서 연 Claude Code 세션만 보입니다. Claude 앱에서 연 세션은 앱의 세션 목록(`~/Library/Application Support/Claude/claude-code-sessions`)에서, 터미널에서 연 세션은 `~/.claude/projects` 의 기록 파일에서 찾습니다.

## 빠른 시작

데스크톱 앱으로 쓰는 방법입니다. Dock 에는 뜨지 않고 메뉴 막대에 고양이 아이콘만 뜨는 앱이고, 수집기도 앱이 직접 켜고 끕니다.

```bash
git clone https://github.com/wad-woojeongmin/agent-cats.git
cd agent-cats
bash desktop/build.sh      # 이 폴더에 고양이팀.app 을 만든다
open 고양이팀.app
```

1. 처음 켜면 `팀.example.json` 을 복사해 `팀.json` 을 만듭니다.
2. `팀.json` 의 `match` 를 내 프로젝트 폴더 이름이나 세션 제목에 들어갈 말로 고칩니다. 메뉴 막대 고양이 아이콘 → 팀원 관리에서 고쳐도 됩니다.

### 다른 방법: 브라우저 화면

앱 없이 브라우저로 볼 수도 있습니다. 터미널에서 수집기를 켜고, 화면을 열어 두는 동안 켜 둡니다.

```bash
python3 수집.py --loop
```

그다음 `index.html` 을 더블클릭해서 엽니다. 15초마다 저절로 갱신됩니다.
수집기가 꺼져 있으면 화면 위에 "수집기가 꺼져 있어요"가 뜨고, 오른쪽 위에 마지막 갱신 시각이 항상 보입니다.

## 고양이 설정 (팀.json)

`팀.json` 은 내 컴퓨터에만 두는 설정이라 git 에 올라가지 않습니다. 없으면 수집기나 앱을 처음 켤 때 `팀.example.json` 을 복사해 만들어 주고, `cp 팀.example.json 팀.json` 으로 직접 만들어도 됩니다.
`cats` 목록에 고양이 하나당 한 줄을 씁니다.

| 항목 | 뜻 |
| --- | --- |
| `key` | 겹치지 않는 영문 이름 |
| `match` | 찾을 말 목록. 세션 제목이나 작업 폴더 **경로 전체**에 하나라도 들어 있으면 이 고양이 담당입니다 (대소문자 무시, 유사어를 같이 적으세요) |
| `name`, `role` | "이름 직군"으로 나옵니다. 브라우저 화면은 고양이 아래 이름표, 데스크톱은 자세한 말풍선 첫 줄입니다. 이름이 없으면 직군만 나옵니다 |
| `variant` | 품종: `white`, `tabby`(줄무늬), `gray`, `tux`(턱시도), `siamese`(샴). 비우면 `white` |
| `prop` | 소품: `headphones`, `glasses`, `postit`, `chart`, `paper`, 비우면 컵만 |
| `task` | (선택) 일하는 중에 말풍선 제목으로 쓸 말. 없으면 "폴더이름 작업중" |
| `fixed` | (선택) 세션과 무관하게 고정으로 띄울 상태. `{"main": "배포 대기중", "sub": "시작 신호를 기다리는 중"}` 처럼 씁니다. 이 고양이는 `match` 를 쓰지 않습니다 |
| `private` | (선택) true 면 세션의 마지막 보고 문장, 폴더 이름, 파일 이름을 싣지 않습니다. 말풍선에는 "파일을 고치는 중" 같은 일반적인 말만 나옵니다 |
| `hidden` | (선택) true 면 두 화면 모두에서 숨깁니다 (데스크톱 앱의 표시 토글이 씁니다) |

맨 위의 `title`, `catWidth`, `columns` 는 브라우저 화면의 제목, 고양이 너비, 한 줄에 놓을 고양이 수입니다. `staleSec`(기본 60) 초 동안 갱신이 없으면 "수집기가 꺼져 있어요"가 뜹니다.

여러 세션이 걸리면 가장 최근에 움직인 세션 하나가 그 고양이의 상태가 됩니다. 아무 세션도 안 걸리면 "아직 일을 시작 안 했어요"로 잡니다.
`팀.json` 은 수집기가 10초마다 다시 읽으니 고친 뒤 바로 반영됩니다. 데스크톱 앱의 팀원 관리에서 저장하면 그 자리에서 다시 수집합니다.

## 고양이 상태와 말풍선

| 상태 | 고양이 | 언제 |
| --- | --- | --- |
| 일하는 중 | 모니터 앞에서 타닥타닥 칩니다 | 아래 판정 |
| 쉬는 중 | 몸을 말고 잡니다. 데스크톱에서는 돌아다니며 놉니다 | 세션은 있지만 일하는 중이 아닐 때 |
| 세션 없음 | 잡니다 | `match` 에 걸리는 세션이 없을 때 |
| 고정 | 모니터 없이 종이를 들고 앉아 기다립니다 | `fixed` 가 있을 때 |

일하는 중 판정은 두 가지입니다. 기록이 5분 안에 움직였거나, 기록이 조용해도 응답이 아직 안 끝났으면(긴 도구나 에이전트를 기다리는 중) 45분까지는 일하는 중으로 봅니다.

브라우저 화면의 말풍선은 세 줄입니다.

- 첫 줄: 일하는 중이면 "{업무명} 작업중..", 쉬는 중이면 "잠깐 쉬는 중"
- 둘째 줄: 지금 진행 중인 작업 (마지막 보고의 첫 문장, 없으면 쓴 도구와 대상)
- 셋째 줄: 마지막 움직임이 언제였는지

데스크톱 앱에서는 두 가지 말풍선이 뜹니다.

- 짧은 말풍선: 지금 하는 일을 한 줄로 4초 동안 보여줍니다. 기본 1분마다 뜨고, 행동 설정에서 주기를 바꾸거나 끌 수 있습니다.
- 자세한 말풍선: 고양이를 클릭하면 브라우저 화면과 같은 세 줄이 8초 동안 뜹니다.

## 데스크톱 앱

### 조작

- 고양이를 **클릭**하면 자세한 말풍선이 뜹니다.
- **끌어서** 옮길 수 있습니다. 창 윗변이나 메뉴 막대 근처에 놓으면 그 위에 앉습니다.
- **우클릭** 메뉴: 여기에 고정 / 고정 풀기, 다른 디스플레이로 보내기(디스플레이가 여러 개일 때), 이 고양이 숨기기, 팀원 관리 열기.
- 고양이가 없는 곳의 클릭은 모두 아래 창으로 그대로 갑니다. 말풍선도 클릭을 막지 않습니다.

### 행동

쉬는 고양이는 아래 행동 중 하나를 골라 합니다. 메뉴 막대 고양이 아이콘 → 행동 설정에서 하나씩 켜고 끌 수 있습니다.

- 걷기, 달리기, 점프, 스트레칭
- 커서 쫓기
- 창 위에 올라가기, 창 주변에서 놀기, 메뉴 막대에 앉기
- 파일/폴더와 놀기
- 서로 놀기

앉기, 쉬기, 자기는 늘 켜져 있습니다. 일하는 고양이는 모니터 앞에 앉아 있고, 고정한 고양이는 그 자리에서 앉거나 쉬거나 잡니다.

### 여러 디스플레이

디스플레이가 여러 개면 디스플레이마다 고양이를 나눠 띄웁니다. 고양이는 자기 디스플레이 안에서만 돌아다닙니다.

- 처음에는 고양이가 적은 디스플레이부터 차례로 나누고, 한 번 정해진 자리는 기억합니다. 다른 고양이를 옮겨도 나머지는 그대로 있습니다.
- 우클릭 → "다른 디스플레이로 보내기"나 팀원 편집의 "디스플레이"로 옮깁니다. "고양이가 적은 화면으로"를 고르면 그 순간 가장 한가한 화면으로 갑니다.
- 자리의 디스플레이를 빼면 그동안은 주 화면에 있다가, 다시 꽂으면 돌아갑니다. 새로 꽂은 디스플레이에는 직접 보낸 고양이만 갑니다.

### 메뉴 막대 설정

- 펫 활성화: 고양이를 모두 띄우거나 내립니다.
- 팀원 관리: 고양이 목록입니다. 끌어서 순서를 바꾸고, 스위치로 표시 여부를 바꿉니다. `…` 에서 편집과 삭제를 하고, "고양이 추가"로 새 고양이를 만듭니다.
  - 편집: 이름, 직군, 품종, 소품, 찾을 말(쉼표로 구분), 업무명, 마지막 보고 문장을 읽지 않기, 데스크톱에 보이기, 디스플레이(여러 개일 때). 저장하면 `팀.json` 에 씁니다.
- 행동 설정: 행동별 켜고 끄기, 활동량(느긋하게 ~ 활발하게), 상태 말풍선 주기(끔 / 30초 / 1분 / 3분)
- 기타 설정: 투명도, 크기, 로그인할 때 자동으로 켜기, 수집기 상태와 다시 켜기, 모든 고정 풀기, 화면 새로고침, 고양이 팀 종료

### 권한

"파일/폴더와 놀기"는 Finder 에 바탕화면 아이콘 위치를 물어봅니다. 처음에 자동화 권한을 묻고, 거부하면 그 행동만 꺼집니다. 나중에 켜려면 시스템 설정 → 개인정보 보호 및 보안 → 자동화에서 고양이팀의 Finder 를 켜세요.

"로그인할 때 자동으로 켜기"를 바꾸지 못하면 그 아래에 안내가 뜹니다. 이때는 시스템 설정 → 일반 → 로그인 항목에 `고양이팀.app` 을 직접 추가하세요.

## 개인정보

- 수집기가 읽는 것은 세션 제목, 작업 폴더 경로, 마지막 활동 시각, 마지막 도구와 대상, 마지막 보고의 첫 문장입니다. 대화 전체를 저장하거나 보내지 않습니다.
- 민감한 내용이 오갈 수 있는 팀은 `private: true` 로 두세요.
- `status.js` 는 실행할 때마다 바뀌는 파일이라 `.gitignore` 에 들어 있습니다.
- `팀.json` 도 프로젝트나 폴더 이름이 들어갈 수 있어 `.gitignore` 에 들어 있습니다. 공유할 예시는 `팀.example.json` 에 둡니다.

## 자주 막히는 곳

### 공통

- 모든 고양이가 "아직 일을 시작 안 했어요"로 잔다: `match` 에 적은 말이 폴더 경로나 세션 제목에 실제로 있는지 확인하세요.
- 세션이 목록에 안 잡힌다: Claude 앱에서 연 세션은 앱의 세션 목록에서(보관한 세션은 빼고), 터미널에서 연 세션은 `~/.claude/projects` 의 기록 파일에서 찾습니다. 터미널 세션은 최근 이틀 안에 움직인 것만 봅니다.

### 브라우저

- 옛 화면이 보인다: 주소 뒤에 `?v=2` 처럼 붙여 새로고침하세요.
- 수집기를 고쳤는데 그대로다: `--loop` 로 켜 둔 프로세스를 끄고 다시 켜세요.

### 데스크톱

- "고양이 팀 폴더를 찾지 못했어요"가 뜬다: 앱이 놓인 폴더를 프로젝트 폴더로 씁니다. `고양이팀.app` 을 `desktop.html` 이 있는 이 폴더 안에 그대로 두세요.
- 터미널에서 `python3 수집.py --loop` 를 같이 켜 둬도 괜찮습니다. 둘 다 `status.js` 를 임시 파일에 쓴 뒤 한 번에 바꿔 넣습니다.
- 화면(`*.js`, `*.css`, `desktop.html`)을 고쳤으면 메뉴 막대 고양이 아이콘 → 기타 설정 → 화면 새로고침, Swift 코드를 고쳤으면 `bash desktop/build.sh` 로 다시 빌드하세요.

## 개발

### 파일

| 파일 | 역할 |
| --- | --- |
| `팀.json` | 고양이 설정 (여기만 고치면 됩니다). 내 컴퓨터에만 두는 파일이라 git 에 안 올라갑니다 |
| `팀.example.json` | `팀.json` 예시. `팀.json` 이 없으면 처음 실행할 때 이걸 복사합니다 |
| `수집.py` | 세션을 찾아 `status.js` 를 씁니다 (`--loop` 는 10초마다, `--config 파일` 은 다른 설정으로) |
| `index.html`, `style.css`, `app.js` | 브라우저 화면과 말풍선 로직 |
| `lines.js` | 상태별 말풍선 문구 (두 화면이 함께 씀) |
| `desktop.html`, `desktop.css` | 데스크톱 앱 화면 |
| `desk-world.js`, `desk-brain.js`, `desk-view.js` | 데스크톱 세계(창·메뉴 막대·아이콘), 고양이 행동, 그리기와 조작 |
| `desktop/*.swift`, `desktop/build.sh` | 데스크톱 앱 (디스플레이별 투명 패널, 메뉴 막대 설정, 수집기 실행) |
| `tests/sim.js`, `tests/assign_test.swift` | 고양이 행동 모의 시험, 디스플레이 배치 규칙 시험 |
| `cats.js`, `pose-*.js`, `props.js`, `palette.js` | 도트 고양이 그리기 (`pose-move.js` 는 걷기·달리기·점프 등) |
| `프롬프트.md` | 이 화면을 Claude Code 로 처음부터 만들 때 쓴 프롬프트. 새 세션에 붙여 넣어 쓸 수 있습니다 |
| `docs/screenshot.png` | 이 README 의 스크린샷 |

### 새 품종·소품 만들기

- 품종: `palette.js` 의 `CAT_VARIANTS` 에 한 줄을 더합니다 (색 덮어쓰기와 무늬 방식 `patch`/`stripes`/`mask`).
- 소품: `props.js` 에 함수를 더합니다 (`head`, `monitor`, `screen` 중 필요한 것).
- 그림은 44x25칸의 도트이고 면만 채우면 테두리는 자동으로 둘러집니다 (`pose-sit.js`, `pose-sleep.js`, `pose-move.js`).
- 데스크톱의 움직이는 자세(`pose-move.js`)는 오른쪽을 보는 옆모습이고 발끝은 20번 줄입니다. 안경과 헤드폰은 `props.js` 의 `"side"` 로 얹습니다.

### 테스트

프로젝트 폴더에서 실행합니다.

```bash
node tests/sim.js
swiftc -swift-version 5 -parse-as-library desktop/DisplayAssign.swift tests/assign_test.swift -o /tmp/assign_test && /tmp/assign_test
```

- `tests/sim.js`: 브라우저 없이 `desk-world.js` 와 `desk-brain.js` 를 20분 돌려 봅니다. 의존성이 없고, 실패하면 0 아닌 값으로 끝납니다.
